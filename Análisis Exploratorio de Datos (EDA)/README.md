#  EDA - Familias Focalizadas del Programa de Renta Ciudadana

## Descripción

Este proyecto consiste en un Análisis Exploratorio de Datos (EDA) utilizando información pública del programa de Renta Ciudadana de Colombia.

El propósito es comprender la distribución geográfica de las familias focalizadas, identificar patrones relevantes y evaluar la calidad de los datos mediante procesos de limpieza y exploración.

---

## Objetivos

Responder las siguientes preguntas:

* ¿Cuántas familias fueron focalizadas?
* ¿Qué departamentos concentran más beneficiarios?
* ¿Qué municipios presentan mayor participación?
* ¿Existen problemas de calidad en los datos?
* ¿Cómo se distribuye geográficamente la población beneficiaria?

## Proceso de Análisis

### 1. Carga de Datos

Importación del archivo CSV utilizando Pandas.

### 2. Limpieza de Datos

* Identificación de valores nulos.
* Eliminación de registros duplicados.
* Normalización de nombres de columnas.
* Revisión de inconsistencias en variables categóricas.

### 3. Transformación de Datos

* Estandarización de variables.
* Conversión de tipos de datos.
* Agrupación de categorías cuando fue necesario.

### 4. Exploración de Datos

* Estadística descriptiva.
* Distribución de registros.
* Análisis geográfico.
* Identificación de patrones.
