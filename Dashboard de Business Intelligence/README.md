# Dashboard Interactivo de KPIs - Superstore Dataset

## Descripción

Este proyecto consiste en el diseño y desarrollo de un dashboard interactivo en Power BI utilizando el conjunto de datos **Superstore**.

El propósito es monitorear indicadores clave de desempeño (KPIs) relacionados con ventas, ganancias, clientes y distribución geográfica, permitiendo identificar tendencias, analizar el rendimiento comercial y apoyar la toma de decisiones basadas en datos.

## Proceso de Desarrollo

### 1. Carga de Datos

Importación del conjunto de datos Superstore desde un archivo Excel/CSV en Power BI.

### 2. Limpieza de Datos

- Validación de registros incompletos.
- Revisión de valores nulos.
- Corrección de formatos de datos.
- Verificación de consistencia en categorías y regiones.

### 3. Transformación de Datos

- Creación de medidas DAX para KPIs.
- Conversión de tipos de datos.
- Optimización del modelo de datos.
- Preparación de campos para análisis geográfico.

### 4. Modelado de Datos

- Relación entre tablas y atributos.
- Definición de métricas de negocio.
- Creación de indicadores clave de desempeño.

### 5. Visualización de Datos

- Tarjetas KPI para métricas principales.
- Gráficos de barras para ventas y ganancias.
- Gráficos por categoría y región.
- Ranking de clientes.
- Mapa geográfico por estado.
- Segmentadores y filtros interactivos.

## Dashboard

El dashboard permite explorar la información mediante filtros dinámicos y visualizaciones interactivas, facilitando el análisis de datos y la toma de decisiones estratégicas.

### Características principales

- Navegación intuitiva.
- Actualización rápida de indicadores.
- Segmentación por estado y métricas de ventas.
- Visualización geográfica de resultados.
- Comparación de desempeño entre categorías, regiones y clientes.
