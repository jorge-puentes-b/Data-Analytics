Bienvenido a mi portafolio de Análisis de Datos. En este repositorio encontrarás una colección de proyectos desarrollados para fortalecer mis habilidades en análisis, visualización, automatización y modelado de datos.

# Proyectos

## Proyecto 1 - Análisis de Ventas

**Objetivo:** Analizar datos de ventas para identificar tendencias, productos destacados y oportunidades de mejora.

**Habilidades aplicadas:**
- Limpieza de datos
- Análisis exploratorio (EDA)
- Visualización de datos
- Generación de insights

**Link a la base de datos:**
 https://www.kaggle.com/datasets/keremkarayaz/coffee-shop-sales

**Estado:**  Desarrollado
